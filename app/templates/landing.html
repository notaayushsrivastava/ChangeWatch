QUESTIONS & ANSWERS

Frequently Asked Questions

How does ChangeWatch prevent false-positive change alerts? ↓
ChangeWatch applies a multi-stage noise normalization pipeline before computing SHA-256 content hashes. Relative timestamps (like "5 minutes ago"), ISO dates, and dynamic view/like counters are systematically sanitized. You can also specify ignore CSS selectors or sensitivity thresholds.
How is server-side request forgery (SSRF) blocked? ↓
Every URL is checked against RFC 1918 private IPv4 subnets, IPv6 loopbacks, localhost hostnames, and cloud metadata IP ranges (169.254.169.254) prior to navigation. In addition, Playwright's network routing intercepts all outbound subrequests and aborts any malicious redirects.
What happens when a monitored site doesn't change? ↓
ChangeWatch enforces a strict store-on-change policy. When a check run detects identical normalized content, it only updates execution logs and timestamps. Unchanged screenshots and DOM copies are never stored, preventing disk bloat.
Can I monitor single elements like prices or changelogs? ↓
Yes! You can use the Interactive Region Studio to visually click any element to watch. You can also configure Numeric Value Tracking to follow prices or stock numbers over time, with automatic trend lines.
