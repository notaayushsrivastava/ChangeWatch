Model Context Protocol (MCP) Integration

Connect Claude Desktop, Cursor, or autonomous AI agents directly to your ChangeWatch account. Empower your AI to create web monitors, trigger headless checks, analyze visual & text diffs, and inspect anomalies with full OAuth 2.0 user-account isolation.

#quickstart #claude-desktop #cursor-ide #oauth-security #tools-reference

1. Server Endpoints

Streamable HTTP (MCP 2025) Recommended

Streamable JSON-RPC HTTP transport supporting RFC 8414 OAuth 2.0 discovery.

Server-Sent Events (SSE) Fallback

Bidirectional SSE connection with message handling endpoint at /sse/messages/.

2. Claude Desktop Setup

To connect Claude Desktop, add ChangeWatch to your claude_desktop_config.json file using mcp-remote:

File location: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows) 
{
  "mcpServers": {
    "changewatch": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{{ mcp_http_url }}"]
    }
  }
}
OAuth 2.0 Flow with Claude:

On your first prompt touching ChangeWatch, Claude Desktop will automatically pop open your browser to ChangeWatch's authorization consent screen (/oauth/authorize). Click Authorize AI Access to link your account securely.

3. Cursor IDE Setup

  1. Open Cursor Settings → Features → MCP.
  2. Click + Add New MCP Server.
  3. Set Name to changewatch.
  4. Set Type to command with command npx -y mcp-remote {{ mcp_http_url }}, or select SSE/HTTP and enter {{ mcp_http_url }}.
  5. Cursor will now discover all 9 ChangeWatch tools automatically in Composer and Chat!

4. Authentication & Security

ChangeWatch implements a native RFC 8414 & RFC 6749 OAuth 2.0 Authorization Server with RFC 7636 PKCE S256 verification.

Standard OAuth 2.0 Flow

Interactive clients query /.well-known/oauth-authorization-server and complete consent via browser redirect.

Personal Access Bearer Tokens

For headless scripts and CLI tools, copy your personal pre-generated token directly from User Settings →.

5. Available MCP Tools Reference

Tool Name Action Key Parameters Description
list_monitors READ — Query all monitors owned by the user, including status, frequency, and change timestamps.
get_monitor READ monitor_id Inspect monitor configuration, CSS selectors, keywords, and captured version counts.
create_monitor WRITE url, name, interval_minutes, sensitivity Create a new monitor with SSRF security verification and auto-baseline capture.
update_monitor WRITE monitor_id, name, interval_minutes Update frequencies, sensitivity thresholds, CSS region selectors, or keywords.
pause_monitor WRITE monitor_id Suspend scheduled automated checks for a monitor without deleting it.
resume_monitor WRITE monitor_id Resume background polling on a paused monitor.
delete_monitor DELETE monitor_id Safely delete a monitor and purge pending jobs.
trigger_check EXECUTE monitor_id Trigger an immediate headless browser capture, noise suppression, and diff calculation.
get_diff READ monitor_id, from_version_id, to_version_id Retrieve unified text diff lines and change summaries between captured versions.
